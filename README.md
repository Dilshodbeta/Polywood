# LaserMaket Studio

Lazer stanokda (590 × 390 mm stol, 3 mm faner) kesiladigan maketlar generatorlari.
Muallif: **Juraqulov Dilshod**.

- `index.html` — asosiy sayt: generatorlar, 3D koʻrinish, listlarga joylash, SVG / DXF / PDF eksport,
  «〰 Egiluvchan qism» (egiluvchan qoplama kesiklarini sozlash).
- `tools/` — alohida asboblar (sayt ichida iframe orqali ochiladi).

## Ishga tushirish
Brauzerda `index.html` ni oching yoki GitHub Pages ni yoqing:
Settings → Pages → Branch: `main`, papka `/ (root)`. Manzil: https://dilshodbeta.github.io/Polywood/

## Eslatma
Sayt claude.ai artifakt sifatida yaratilgan. Galereya, foydalanuvchi va AI generatsiya kabi
`window.claude` imkoniyatlari GitHub Pages da ishlamaydi; generatorlar, 3D va yuklab olish ishlaydi.
